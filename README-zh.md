# Research Question Forge｜研究问题与框架构建

[English](README.md) | 简体中文

> **让科研重新聚焦于研究本身。**

**提出好问题，比解决问题更重要。** Research Question Forge 致力于帮助科研工作者从观察中发现问题，从问题形成思路，并发展出有意义、有深度的研究构思。通过对话式启发、文献研究与迭代打磨，澄清问题的边界、价值与可行性，回到“研究什么、为什么值得研究、什么问题真正值得被研究”。

[免安装开始](zh/question-forge-guide.md) · [安装 Skill](zh/usage.md) · [English guide](en/usage.md)

## 为什么需要它

研究往往始于检索与写作之前：一个意外观察、实践困难或解释不充分的现象。难点是判断它是否指向知识问题、已有工作回答了多少，以及哪里可能形成可开展的贡献。

Forge 处理这段问题形成过程，为检索、阅读、设计与写作提供更好的问题和框架输入。它支持不同学科与研究阶段，可独立成立，也可融入其他流程。

## 怎样工作

```text
观察 → 初步想法 → 问题抽象
                    ↕
                 文献反馈
                    ↓
             问题拓展／问题拆分
                    ↓
              研究落点 → 研究框架

新证据／反馈 ──→ 问题抽象
            ├─→ 问题拓展／问题拆分
            └─→ 研究框架
            ╌╌→ 反思观察方式、科研想法与问题形成
```

实线表示研究工作中的直接推进与修订：新证据／反馈可同时调整问题抽象、问题拓展／拆分和研究框架。虚线表示更深层的认识论反思：我们为何注意这些现象、如何观察与解释、哪些前提塑造了科研想法，以及如何从观察提出问题。两类反馈都可反复发生，不必等到框架或草稿完成。

从当前阶段进入，每轮讨论少量关键问题；随着证据和认识变化维护框架。涉及研究方向的实质取舍由研究者决定。

## 问题扩展与问题拆分

**Question Expansion：由点及面。** 从局部矛盾发现可能的一般关系、机制或限制，建立观察与意义之间的联系，不把扩大范围当作自动拔高。

**Question Decomposition：由面到点。** 将过大问题拆为子问题，结合时间、材料、能力和证据，找到可研究的具体落点。两种过程都允许因新证据而调整。

## 文献作为反馈

新论文应改变认识，而不仅增加阅读清单：已有答案、更接近的基线、竞争解释、范围收缩或新方向，都可能影响问题。

Forge 记录为什么选择参照、哪些条件可比、已有工作覆盖什么、候选方案可能新增什么及未核项。基线也可以是理论、实践或案例。原文报告、助手推断、预期能力和已复现结果分别记录。

## 什么问题值得研究

考察真实未知、与已有知识的张力、负结果的认识价值、适当尺度、证据路径和可执行落点。

Forge 不自动评判“科研品味”，而是让背后的判断可以说明理由、讨论和修订；不打题目总分，不替研究者选择方向。

## 输出什么

默认维护 **research-framework.md**；比较材料较多时才增加 **research-comparison.md**。

|可独立理解的研究论述|提炼的信息|
|---|---|
|观察、动机与当前认识|对象、条件、事实与未知|
|中心问题、子问题及意义|问题边界与缺口依据|
|最近似研究与竞争解释|来源、角色、可比条件与已有覆盖|
|候选方向与研究落点|方案、可能贡献与约束|
|证据路线与当前决定|核查需求、用户选择、未决项与下一步|

把 **问题 → 已有研究 → 候选方向 → 证据 → 决定** 连起来，形成可讨论的研究论述，不将框架完成当作发现已验证或论文已完成。

## 为组合使用而设计

不绑定特定检索、精读、综述、写作或开题流程。框架可交给用户已有的文献工具、领域 Skill、设计/分析智能体或自建流程；交接保留问题、证据要求、来源、限制和决定。

检索与文件能力取决于宿主；缺少能力时使用已提供材料并列出待核项，不伪造检索或引用。

## 快速开始

将[完整引导](zh/question-forge-guide.md)作为聊天附件，或把完整[中文 Skill 文件夹](zh/research-question-forge-zh/SKILL.md)放入客户端支持的 Skill 目录，保留 references。中英文 Skill 名称独立，可同时安装。

> 使用 $research-question-forge-zh。我观察到……，目前的想法是……，已有文献与条件是……。先帮我形成研究问题，再讨论题目；随着新论文和反馈修订研究框架。

省略号是输入提示，不是研究案例；无需先填长问卷。详见[使用说明](zh/usage.md)。

## 研究原则

- 区分实践目标、知识缺口、问题、方案与题目。
- 保留反证与研究者决定，按学科选择证据。
- 不编造创新、精读、复现、条件或成果。
- 意义有依据，范围可承担。
- 私人研究不得进入公开贡献，匿名化也不等于可公开。
