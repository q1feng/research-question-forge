# 使用说明

[首页](../README-zh.md) · [English](../en/usage.md)

## 免安装

上传[完整引导](question-forge-guide.md)并说明观察/想法、当前材料、可用条件与本轮需求。不必先有最终题目，不必一次填完所有信息。单文件包含全部规则；助手不能写文件时请其输出可保存的 Markdown。云端助手不能自动访问本地路径，需实际提供文件。

## 安装 Skill

将本目录中的完整 `research-question-forge-zh/` 文件夹放入客户端支持的 Skill 目录，保留 SKILL.md、agents 和 references。不要只复制入口文件。不同客户端的安装位置和发现机制以其说明为准；本包不自动修改全局配置。

调用：`使用 $research-question-forge-zh，基于我的材料完成当前阶段，并保持研究决定与证据边界。`

中英文名称不同，可同时安装。若无法识别，可明确要求读取[入口](research-question-forge-zh/SKILL.md)及其引用资料，或改用免安装版。首次使用不需要特定模型、密钥或其他 Skill。

## 接续工作

已有文件时说明位置并沿用；新论文到来时检查受影响的基线、主张和方向，不只追加摘要；反馈修改应解释依据与代价，已经选定的方向直接落实。默认输出文件名不带语言后缀，需要双语产物时分目录。

未知证据如实标记；不把框架、草稿或脚本运行成功当研究结论。实际检索、分析和排版范围由用户请求与可用工具决定。

默认维护 research-framework.md，比较较多时再增加 research-comparison.md。正式综述或报告交给用户选择的下游工作流。
